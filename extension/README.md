# Socmedia CLI Chrome bridge

1. Run `bun run src/cli.ts extension install --json` to copy the unpacked extension into the stable `<state directory>/extension` directory. The result includes its fixed public-key-derived extension ID; `extension path --json` prints the directory. With `--open`, the install command opens `chrome://extensions` in Chrome on macOS.
2. In `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose that stable directory. Confirm the ID shown by Chrome matches the install result.
3. Run `bun run src/cli.ts extension pair --id EXTENSION_ID --json`. Copy the `token` value from the output; it is a secret. The service stores it locally in a mode-0600 file. Re-pairing replaces the old secret; restart an already running service to disconnect previously paired clients. Installing does not change an existing pairing.
4. Open the Socmedia extension popup, paste the token into **Pairing secret**, and select **Save**. The extension stores it in its local Chrome storage.
5. Start the service with `bun run src/cli.ts service start --json`. Run `bun run src/cli.ts service status --json`; `version` and `extension.version` show the full versions, and `extension.compatible` reports whether major and minor versions match.

The default endpoint is `127.0.0.1:47842`, separate from the old bridge. Use `socmedia config set port PORT --json` to save a port, `config get port` to inspect its source, or `config unset port` to return to the default. `SOCMEDIA_EXTENSION_PORT` overrides saved config. Restart the service after changing its port; `service status --json` shows the running endpoint and source. Set the matching port in the extension popup and save it; the extension reconnects without changing the pairing secret. `socmedia tabs list --json` lists the separate Socmedia CLI group and selected tab. Use `socmedia tabs use TAB_ID --json` to select an open Instagram, Facebook or YouTube tab, and `socmedia tabs clear --json` to return to the group. `socmedia queue enqueue readPage --args '{"maxLines":200}' --json` queues a read-only page-text job; inspect its result with `socmedia queue get ID --json`. Other than profile reading, no other queued browser actions are implemented. The new extension has not yet been tested live in Chrome. Reload the extension in Chrome after updating its files.

Both sides authenticate with HMAC-SHA-256 challenges containing fresh nonces; the stored pairing secret is never sent over the WebSocket. Browser requests are accepted only after the extension verifies the service's proof. The service also checks the configured Chrome extension Origin before the handshake.

`socmedia page snapshot --json` queues and returns visible interactive elements of the work tab; `socmedia queue enqueue snapshot --json` queues the same operation for later inspection. If `readPage`, `snapshot` or `getProfile` detects a login, checkpoint, challenge, CAPTCHA or a known restriction message, the service records `HALT` and pauses the queue, including after restart. Resolve the issue yourself in Chrome, then run `socmedia service resume --json`; the next read checks the page again. Detection uses page URLs and visible English UI signals and has not yet been verified live in Chrome.

`socmedia profile get URL --json` reads an Instagram or Facebook profile/page through the work tab and queue and stores or updates its local contact. Facebook supports profile slugs, numeric `profile.php?id=...`, and `/people/<slug>/<id>` or `/pages/<slug>/<id>` paths; redirects to a different profile fail. `socmedia contacts list --json` lists contacts; `socmedia contacts update ID --status STATUS --note TEXT --json` updates status and/or note. `socmedia contacts export --format csv|json|jsonl --path PATH --json` writes contacts inside the service user's home directory (optionally filtered by `--status` and `--platform`). Importing existing contacts is not implemented yet. Extraction uses page metadata and visible English UI text; fields may be null or incomplete, and the new implementation has not been tested live in Chrome.
